# PowerStep Grid — السوفت وير (نسخة المحاكاة)

نظام محاكاة كامل + لوحة تحكم حية، بيوريك بيانات "واقعية" لمشروع الأرضية المولّدة
للطاقة قبل ما تلمس أي هاردوير خالص.

## 1) المتطلبات

- **Python 3.9 أو أحدث** مثبَّت على جهازك (تأكد بكتابة `python3 --version` في الترمينال).
- متصفح إنترنت عادي (Chrome/Edge/Firefox) — مش لازم إنترنت فعلي لتشغيل الداشبورد نفسها،
  لأن كل حاجة (الخطوط، مكتبة الرسم البياني) متضمَّنة جوه المشروع.

## 2) خطوات التشغيل (أول مرة فقط)

افتح الترمينال (Command Prompt / Terminal) جوه مجلد المشروع، واكتب بالترتيب:

```bash
cd backend
pip install -r requirements.txt
```

الأمر ده هيثبّت مكتبتين بس: `fastapi` (لتشغيل السيرفر) و `uvicorn` (لتشغيله فعليًا).

## 3) تشغيل السيرفر (كل مرة عايز تجرب فيها)

```bash
python -m uvicorn app:app --reload
```

لو ظهرلك سطر شبيه بده يبقى تمام:
```
Uvicorn running on http://127.0.0.1:8000
```

## 4) فتح لوحة التحكم

افتح المتصفح واكتب في شريط العنوان:

```
http://localhost:8000/index.html
```

هتلاقي الداشبورد شغالة وبتتحدث كل ثانية لوحدها. سيب الصفحة مفتوحة وهتشوف الأرقام
بتتغيّر زي ما لو كان فيه ناس بتمشي على البلاط فعليًا.

## 5) إيقاف السيرفر

ارجع للترمينال واضغط `Ctrl + C`.

## هيكل المشروع

```
powerstep-software/
├── backend/
│   ├── app.py            ← السيرفر (FastAPI) — يوفّر البيانات عبر API
│   ├── simulator.py       ← "عقل" المحاكاة — كل المعادلات الفيزيائية هنا
│   └── requirements.txt   ← قائمة المكتبات المطلوبة
├── frontend/
│   ├── index.html         ← لوحة التحكم اللي بتفتحها في المتصفح
│   └── vendor/             ← مكتبة الرسم البياني والخط، محمَّلة محليًا (بدون إنترنت)
└── README.md               ← هذا الملف
```

## من المحاكاة إلى الهاردوير الحقيقي

الملف `backend/app.py` فيه نقطة اتصال اسمها `/api/ingest` مجهّزة (لكن غير مفعّلة بعد)
لاستقبال قراءات حقيقية من ESP32. لما يجهز الهاردوير، هدف الخطوة الجاية هو:
تفعيل هذه الدالة لتحديث حالة النظام من القراءات الحقيقية بدل المعادلات، مع ترك
باقي الكود (API + الداشبورد) كما هو تمامًا.
